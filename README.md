
NutriGuide – AI Optimal Nutrition

NutriGuide is a web application that helps users maintain a healthy, balanced, and personalized diet. The user enters their personal data and goals, logs meals daily, and AI analyzes the intake in real time, calculates nutritional values, provides smart recommendations, and tracks progress toward the goal.

Main Features
1. User Account and Profile
Registration and login
Create and edit profile: gender, age, height, weight, daily activity level, and goal (weight loss, maintenance, or gain)
2. AI Calculation of Optimal Daily Targets

Based on entered data and selected goal, AI automatically calculates:

optimal daily calorie intake
precise macronutrient breakdown (proteins, carbohydrates, fats)
recommended fiber intake

Targets are automatically updated if the user changes weight or goal.

3. Daily Meal Logging
Simple text input (e.g. “I ate a banana and yogurt”)
AI estimates calories and nutritional values of the intake in real time
Daily targets are automatically updated after each entry
Option to save favorite meals for quick future logging
4. Smart AI Recommendations
Suggestion for the next meal based on previous intake
(example: ate a banana for breakfast → AI suggests protein-rich meals for lunch)
Enter how you feel (tired, bloated, weak, nauseous…) → AI analyzes the last 48 hours of nutrition and suggests a meal that will help you feel better
5. Meal History in Calendar
Interactive calendar showing all logged entries by day
Click on a date to view details: what was eaten, calorie/nutrient totals, how the user felt that day
Quick access to past days for analysis and comparison
6. Weekly Reports and Progress Tracking
Overview of how the user felt during the week
Analysis of diet balance and proximity to daily targets
AI-generated textual summary
Weekly progress overview: at the end of each week the user enters their current weight → the application displays:
weight change compared to the start
progress toward the goal
7. Quick Logging via Messaging Platforms
Integration with external messaging app for easier meal logging
User can send a meal directly via chat (e.g. “ate 2 eggs and bread”) – the entry is automatically recorded in the application
